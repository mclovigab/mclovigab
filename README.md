## Sobre mim

Olá! Sou João Gabriel, estudante de Análise e Desenvolvimento de Sistemas (ADS), com interesse em tecnologia, programação e desenvolvimento de software.

Utilizo o GitHub para organizar meus estudos, praticar conceitos de programação e desenvolver projetos que contribuam para minha formação acadêmica e profissional.

Acredito que aprender na prática é fundamental para evoluir. Por isso, busco transformar o conhecimento adquirido em exercícios, experimentos e projetos, registrando minha evolução ao longo dessa jornada.

## Formação e conhecimentos

- **Formação em andamento:** Análise e Desenvolvimento de Sistemas (ADS).
- **Desenvolvimento web:** HTML, CSS e JavaScript.
- **Ferramentas de desenvolvimento:** Visual Studio Code.
- **Controle de versão:** Git e GitHub.

Estou desenvolvendo meus conhecimentos gradualmente, buscando compreender os fundamentos da programação e aplicá-los em projetos práticos.

## Objetivos

Meu objetivo é ampliar meus conhecimentos em tecnologia, aprimorar minhas habilidades de programação e construir uma trajetória profissional na área de desenvolvimento de software.

Este perfil reúne meus estudos, exercícios, projetos acadêmicos e experimentos pessoais, acompanhando meu progresso como estudante e desenvolvedor em formação.
